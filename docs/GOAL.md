# 프로젝트 최종 목표 (v2.0)

수집된 공개 데이터를 바탕으로 PF 사업장의 가격 변동 요인을 시계열로 분석하고,
실무자가 직접 조회/분석할 수 있는 Streamlit 대시보드 앱을 구축하여 퍼블릭으로
배포한다. 나아가 이 성과를 AI 공모전에 출품한다.

## Phase 1: 통계 및 데이터 정합성 확보 (최우선) — ✅ 완료

- 처음부터 다시 돌린 전수 통계로 변수 간 관계 확인 → `docs/PHASE1_findings.md`
- 논리적·통계적으로 유의미한 변수만 확정해 패널 고정 → `data/panel_clean.csv` (62열)
- 사내 정보 첨부 시 확장 가능한 구조 → `pipeline/variable_catalog.json` + `build_panel.py --internal`

## Phase 2: Streamlit 앱 대시보드 개발 — ✅ 완료 (로컬 검증)

- 지역(권역/시도) · 종류(대분류 + 세부: 아파트/오피스텔/물류센터/공장 등) 자유 필터 UI
  ※ 냉동/냉장 물류창고 구분은 원천 데이터에 없어 '물류센터'로 통합됨
- 필터 대상 사업장의 감정가/최저입찰가/매각가 시계열 시각화 (집계 + 개별 경로 + 사건 마커)
- 사내 데이터 입력 파이프라인 Placeholder (업로드 → 스키마 검증 → `int_` 격리 결합)

## Phase 3: 비즈니스 인사이트 도출 로직 — ✅ 완료

- 규칙 기반·설명 가능 위험 스코어 8종(가중치 조정 가능) → '위험 스크리닝' 탭
- 각 규칙은 Phase 1 통계 근거에 연결됨
