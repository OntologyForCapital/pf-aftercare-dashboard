# AI 공모전 제출 자료 (초안)

> **익명화 원칙**: 본 자료의 모든 내용은 개인·소속 기관을 특정할 수 없도록
> 일반화하여 작성한다. 작성자는 "금융업 종사 실무자 1인"으로만 표기한다.
> 제출 전 최종 익명화 점검 체크리스트(하단) 통과 필수.

## 1. 사용한 AI 서비스

| 서비스 | 용도 |
|---|---|
| Claude Code (Anthropic) | 데이터 수집 파이프라인 구축, 전수 통계 분석, 대시보드 개발, 문서화 |
| OpenAI Codex | 코드·분석 결과 외부 검수(7차례 교차 검증), 정합성 결함 발견·정정 |
| 범용 LLM 챗봇(복수) | 탐색적 아이디어 검증, 보조 통계 스크립트 초안 |

핵심 활용 방식: **작성자(비개발자)가 자연어로 목표·검증 기준을 제시하고, AI가
코드 작성 → 다른 AI가 적대적 검수 → 사람이 판정하는 3자 루프**. 총 7차례의
교차 검수에서 데이터 결함 수십 건을 발견·정정했다(중복 사업장 병합, 자릿수
오기입 격리, 결과 누수(outcome leakage) 제거, 핵심 결론 1건 철회 등).

## 2. 사용한 프롬프트 (대표)

1. **목표 할당 프롬프트** — `docs/GOAL.md` (5단계 Phase 정의, 본 저장소의 설계도)
2. **전수 통계 프롬프트** — "폴더 안에 있는 원자료로 각 변수 간 관계를 확인할 수
   있는지 통계를 다 돌려줘" → 패널 3층 분해·FDR 보정 전수 검정으로 구체화
3. **적대적 검수 프롬프트(외부 AI)** — "이 분석의 수치 재현성·표본 정의·누수
   여부를 공격적으로 검증하라" (7차례 반복)
4. **정합성 규율** — "모든 수치는 산출물에서 재계산되는 단일 정본(canonical
   metrics)과 자동 대조하라"

## 4. AI 산출물 (결과 요약)

- **데이터 자산**: 공개 PF 사업장 798곳 가격 경로 패널(4,732행), 처분 결과 연결
  353곳, 시장 벤치마크 대비 초과할인 8,565회차
- **분석 발견** (통계 검정·FDR 보정·외부 검수 통과):
  - 감정평가액은 하방 경직적(공개기간 중 83.6% 무변동) — 조정은 최저입찰가 인하로만 발생
  - 공매 시작가는 감정가의 120%, 회차당 약 −9.5% 체감, 중앙 체류 7개월
  - 산업시설(물류 포함)은 시장보다 싸게 내놓아도 가장 오래 남는다(수요 부재) —
    체류 위험비 HR 0.62, 초과할인 −4.4%p vs 주거 +20.2%p
  - 신용스프레드 확대 국면에 저감이 깊어지는 방향 신호(차분 상관 −0.68)
  - 지가 상승 지역일수록 공매가 빨리 끝난다(Cox HR 1.34, p=2.6e-7)
- **제품**: 지역·유형 필터, 가격 시계열, 규칙 기반 위험 스크리닝을 갖춘
  Streamlit 대시보드 (퍼블릭 배포)

## 5. 활용 효과

- **비용**: 외부 데이터 구매 없이 공개 데이터만으로 부실 PF 모니터링 체계 구축
- **시간**: 수작업으로 수개월 걸릴 12만+ API 호출·전수 조인·통계 검정을 단기간에 완료
- **품질**: AI 교차 검수 루프로 사람 단독 분석보다 높은 재현성(클린룸 재빌드
  바이트 일치, 회귀 테스트 58종 자동화)
- **실무 적용**: 관리 자산 점검 우선순위 스크리닝 → 사내 비공개 데이터 결합
  확장 슬롯까지 설계(개인정보·내부정보는 로컬 전용, 퍼블릭 배포본과 격리)
