# 사내 데이터 결합 스키마 규약 (Placeholder)

비공개 사내 데이터(여신, 사업성평가, 관리 상태 등)를 공개 패널과 결합할 때의
계약(contract). 결합 실행: `python pipeline/build_panel.py --internal <파일.csv>`
또는 앱 '사내 데이터 결합(준비)' 탭에서 스키마 사전 검증.

## 필수/선택 컬럼

| 컬럼 | 필수 | 형식 | 설명 |
|---|---|---|---|
| `site_id` | 둘 중 하나 | S로 시작하는 사업장 ID | `data/site_master.csv`의 ID와 일치 |
| `address` | 둘 중 하나 | 문자열 | site_id가 없으면 주소로 자동 매칭(공백 제거 후 대조) |
| `month_key` | 선택 | `YYYY-MM` | 있으면 사업장×월 그레인, 없으면 사업장 상수로 결합 |
| (값 컬럼들) | 1개 이상 | 수치/범주 | 자동으로 `int_` 접두사 부여 → 공개 변수와 격리 |

## 규칙

1. **격리 원칙**: 사내 값 컬럼은 전부 `int_*`로 이름이 바뀌어 편입된다. 공개 변수와
   섞이지 않으며, 카탈로그(`variable_catalog.json`)의 `int_*` 예약 슬롯에 대응한다.
2. **그레인 보존**: 결합 후에도 사업장×월×라인 유일성 불변식이 유지되어야 한다
   (빌더가 검증, 위반 시 중단).
3. **주소 매칭 한계**: 표기 변형(동/리 생략, 번지 표기)은 미매칭될 수 있다.
   미매칭 행 수가 보고되며, 정밀 매칭이 필요하면 `site_master.csv`를 참조해
   `site_id`를 직접 부여하는 것을 권장.
4. **보안**: 사내 데이터는 이 저장소에 커밋하지 않는다 (`.gitignore`의
   `internal_*.csv`, `*_internal.csv` 패턴). 앱 업로드는 세션 메모리에서만 처리된다.
   퍼블릭 배포본에는 사내 데이터를 절대 올리지 않는다 — 결합 분석은 로컬 실행으로만.

## 예시

```csv
site_id,month_key,exposure_mn,internal_grade
S10811092,2026-01,4500,C2
S10811092,2026-02,4500,C3
```

→ 결합 후 컬럼: `int_exposure_mn`, `int_internal_grade`
