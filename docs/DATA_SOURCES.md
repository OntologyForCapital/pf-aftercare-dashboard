# 수집·활용 데이터 목록

전부 공개 출처. 본 저장소에는 가공 산출물(패널·요약)만 포함하며, 원천 대용량
캐시는 포함하지 않는다.

## 핵심 (사업장 패널의 뼈대)

| 출처 | 내용 | 사용 |
|---|---|---|
| 전국은행연합회 PF 정보공개 | 경공매 대상 PF 사업장 월별 공시(주소·유형·감정가·최저입찰가·회차·상태) | 사업장 798곳 × 17개월(2025-09 결측) 패널의 본체 |
| 온비드(OnBid) 공매 API | 공매 공고·회차·낙찰 결과 50만 행 | 처분 결과 연결, 시장 벤치마크 대비 초과할인 |
